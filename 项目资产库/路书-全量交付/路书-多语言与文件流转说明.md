# 路书 · 多语言 / 语音 / 文件流转（v3 补丁说明）

本轮在原有工作台上加了四块能力：**界面语言**、**语音输入与朗读**、**上传文件**、**输出文件**。
不设额度限制——上传、解析、导出、切语言都不扣任何东西。

---

## 一、四个模块各自做了什么

### 1. 界面语言（中 / EN）

- 顶栏标签栏右侧一个「文 中」按钮，点开是两行选择器：`简体中文（默认）` / `English（英文）`，当前语言打勾，Enter 确认、Esc 退出（这套交互照搬参考仓库 `dsh-TUI` 的 `/lang` 选择器）。
- 切换是**全站的**：侧栏导航、标签栏标题、命令面板分组、对话页标题/空态/输入区、材料与产出页、统计卡脚注、全局提示。
- 语言存 `localStorage`，下次进来还是上次选的；也支持 `?lang=en` 直达英文（分享链接、截图用）。
- **只翻「导航 + 操作 + 状态」这一层皮。** A–E 五组资料正文不翻译——原文是中文，翻过去就成了二次加工，容易把「原文这么写」变成「我以为它这么写」。
- 英文界面下回答会多一块 `English summary`，顶部固定一行：`English summary — the Chinese original governs`。摘要内容照中文原文写，不新增事实。
- 政策类回答末尾那段固定来源结尾保持中文原文（合规格式不翻译）。

### 2. 语音（一条进、一条出）

**进：语音输入**
- 输入区左下角圆形麦克风。点击开始，按钮变蓝并显示 5 根跳动的波形柱，再点一次结束。
- 用的是浏览器 `SpeechRecognition`（Chrome / Edge 可用），识别到的文字直接写进输入框，**不自动发送**，留给你改。
- 拿不到能力时（浏览器不支持、麦克风没授权、识别服务不可用）走**演示输入**：1.8 秒后填入一句示例问题，并在输入区顶部一条状态栏写明「演示模式 · 未接入真实语音识别」。这一步刻意不做假——假装识别成功，后面全是错的。

**出：朗读回答**
- 每条回答悬停工具条里有「▷ 朗读」，播放中变成「◼ 朗读中」并有脉冲。
- 用 `speechSynthesis`，长文本按标点切成 ≤120 字的小段排队读，避免一次喂进去读到一半断掉。没音色时明确提示读不了。

### 3. 上传文件

三条路都通到同一个列表：

| 方式 | 行为 |
| --- | --- |
| 拖拽 | 文件拖到**整页任意位置**都会浮出遮罩「松手就加上」，不是只接输入框那一条 |
| 粘贴 | `Ctrl + V` 粘贴剪贴板里的图片/文件 |
| 选择 | 「＋ 附件」调系统文件框，可多选 |

- 白名单：`pdf / doc / docx / txt / md / csv / xls / xlsx / png / jpg / jpeg / webp`，单个 ≤ 20 MB，一次最多 8 个。
- 每个文件一张卡：类型徽标、文件名、大小、状态。状态四档：排队 → 解析中（百分比进度条）→ 已读 N 段 / 失败。
- 失败有两类，文案分开：`超过 20 MB`、`暂不支持这个格式`。
- 文本类文件会真读前 4000 字，卡片下面显示一行摘要；图片用 `URL.createObjectURL` 出缩略图。
- **文件不出浏览器**：没有上传接口，全部本地读取。页面底部写明「都在本地，没上传服务器」。
- 发送后附件跟着这条问题进消息，右侧「本次来源」里也会多出「你的附件」几条，每条都标：**仅作补充材料，不作为回答出处——出处仍然只认 A–E 五组。**

### 4. 输出文件

**a. 回答里的「本次产出」**
- 命中知识库的回答下方会挂 1–2 个文件卡：`专插本准备清单.md`、`升学就业路径对照.csv`、`计算机应用技术-对口岗位.csv`、`岗位对照说明.md`、`大一行动清单.md`、`简历检查表.md`。
- 卡片先显示「生成中 + 进度条」，涨满才变「可下载」——不给点了没反应的空按钮。
- 三个操作都是真的：**预览**就地摊开前 40 行；**下载**走 Blob 真实落地（CSV 带 BOM，Excel 打开中文不乱码）；**复制链接**（演示环境，链接只在本机有效，卡片下方写明了）。
- 文件内容全部从回答原文里拆，不新增资料里没有的数字。所以「考编」那一行照实写「现有资料未覆盖」，不给条件也不给目录。

**b. 各页「导出」**
- 看清路：岗位对照 CSV / Markdown / 复制为表格
- 路线图：任务清单 CSV / Markdown（带 `- [x]` 勾选状态与完成度）
- 调用日志：日志 CSV / Markdown 表格 / 复制为表格
- 材料与产出：材料+产物清单三件套
- 菜单底部一行小字：**导出不计额度**。

**c. 新材料与产出页**
- 侧栏「学生工作台」下多一项，路由 `/page/materials`。
- 四张统计卡：材料 / 已解析 / 产出 / 合计大小。
- 左栏「我的材料」：文件名、大小、来源、时间、状态徽章（已读 N 段 / 失败原因），可单条移除。
- 右栏「产出的文件」：复用产物卡，能预览、下载、复制链接。
- 两个空态都写了下一步该干什么，不是一句「暂无数据」。

## 三、有意没做的

| 没做 | 原因 |
| --- | --- |
| 真实上传接口 / OCR / 文档解析后端 | 演示环境没有服务端；假接口比没有接口更糟 |
| 把文件存到服务器或云端 | 材料是学生隐私，原型阶段不上传 |
| 翻译 A–E 资料正文 | 二次加工会改变原文意思，且政策类必须保留中文原文口径 |
| 语音唤醒 / 常开麦克风 | 隐私与误触，且识别能力依赖浏览器 |
| 积分扣费 / 额度限制 | 按你的要求，这些操作都不设额度 |
| 产物按真实 LLM 生成 | 没有模型调用；内容全部由已有回答拆出，宁可少也不编 |

## 四、怎么验（3 分钟）

1. 打开 `/#/page/chat-workspace`，把 4 个文件（含一个 `.exe`）拖进页面 → 看拖拽遮罩、四种状态、失败红色提示。
2. 点左下角麦克风 → 看状态栏「演示模式 · 未接入真实语音识别」，示例问题进输入框。
3. 发「专插本报名要什么条件」→ 回答下方出现两张产物卡；点「预览」看弹层，点「下载」看文件真的落地。
4. 点顶栏「文 中」→ 切 English → 摘要出现在正文之前，导航/按钮/状态全英文，资料正文仍是中文。
5. 侧栏进「材料与产出」→ 左边 4 份材料、右边 2 个产出，统计卡对得上。
6. 看清路 / 路线图 / 调用日志右上角「⇩ 导出」→ 选 CSV，Excel 打开不乱码。
