**取包方式**：`file_download` 拿签名 URL → `curl -sSL --noproxy '*' -o 目标.zip "URL"`。
**传包方式（有坑）**：`curl -T` 直接带 `Authorization` 会报 `SignatureDoesNotMatch`。可行路径是 python 生成 curl 配置文件（`url` / `request` / `upload-file` / `header` 各一行）→ `curl -sS -K up.conf --noproxy '*'` → 拿到 200 → 再调 `file_upload_complete`。另外 python 里的 `/tmp` 在 Windows 实际是 `C:\tmp`，配置要写工作区相对路径。

## 五、VTJ 的坑（血泪版）

- 模板/methods 内访问响应式：`this.xxx.value`；`vFor` 用 `this.context.item`。
- `watch` 写数组；`lifeCycles` 写对象；动态 class 用 `js()`。
- DSL 辅助库 `patch/vtj.py`：`div(cls, text)` 是**先 class 后文本**；`span` 要先文本 `V.span(text, cls=...)`；`V.el('span','文字',cls=...)` 会报 multiple values。
- 新增页面光加 `src/views/x.vue` 会 404，必须注册进 `.vtj/projects/msr150174.pages9.json` 的 `MainLayout.children`。
- Vue 响应式陷阱：`ref([]).push(raw)` 后继续改 `raw`，产物卡不出现、进度卡 0%。要用数组里的代理对象；附件解析放 `watch(() => props.files)` 里启动。
