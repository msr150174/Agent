# 路书 · 职业规划知识库（统一调用索引 · v1.2）

> 本索引把**两套知识库**打通成可被智能体统一检索的体系：
> 1. **学校行动层**——《职业规划_知识库_v1.1.md》（专业→岗位→技能/证书→薪资→简历→面试→权益，广州市高职院校口径）。
> 2. **大湾区区域层**——8 个 `A_/C_/E_*.md` 区域条目（粤港澳大湾区“9+2”企业人才宏观数据，来源《粤港澳大湾区企业人才现状与发展趋势：2025》）。
>
> **机器可读目录**：同目录 `kb_index_v1.2.json`（25 条，含 `group_code / kb_variable / table_hint / canvas_node`），对应库表 `idx_entry`。
> 所有路径相对本 `v1.2/` 目录。

> 版本：v1.2　|　编制：2026-11-12　|　对应库：`lu_shu_kb_v1.2.db`

## 一、两套库的定位与关系

| 维度 | 学校行动层（职业KB） | 大湾区区域层（区域条目） |
|---|---|---|
| 文件 | `职业规划_知识库_v1.1.md` | `A_受访企业画像.md` 等 8 篇 |
| 口径 | 本校专业 / 珠三角 | 粤港澳大湾区 9+2 |
| 来源等级 | 官方/市场/自建混合 | 市场（调研报告，样本 N≈116） |
| **证据级别（v1.2 新增）** | **原文入库**，可按句回查 | **仅索引级**：原文未入库，只能引标题级数字 |
| 回答的是 | “我的专业能投什么岗、怎么写简历、薪资区间、权益” | “大湾区整体行情、哪些行业缺人、政策靠不靠谱、AI 冲击” |
| 互补关系 | 给**落地动作** | 给**区域背景**；两者组合才完整 |

**铁律（沿用职业KB §〇）**：事实只来自知识库；金额/日期/条件须带文件名与生效日期；不做心理诊断、不承诺录取与薪资；薪资只写分位数+口径，绝不写“月薪X起”。

> ⚠ v1.2 新增红线：区域层 8 篇原文不在库内，**细分数字（如内推 63.7%、宣传不到位 51.0%）不得引用**，只能引 `idx_region.data_points` 里登记过的、能从标题/标签对上的数字（见缺口 G15）。

## 二、统一查询字段（智能体过滤用）

`id` · `system`(profession/region) · `file` · `section` · `title` · `category` · `topic` · `scope` · `source_level`(官方/市场/自建/混合) · `source` · `effective_from` · `verified_at` · `tags` · `related`

**v1.2 新增 4 个字段**（用于把索引直接接到表和画布）：
`kb_variable`（主变量名）· `group_code`（9 个检索分组）· `table_hint`（优先查哪些表）· `canvas_node`（画布节点 id）

- `topic` 统一取值：**综合 / 专业 / 岗位 / 证书 / 简历面试 / 政策 / 区域市场趋势 / 求职策略**（区域条目原 `category` 的 A/C/E 保留在 `category` 作采集分组追溯）。
- `scope` 取值：**学校/珠三角** 或 **粤港澳大湾区**；`source_level` 取值：**官方 / 市场 / 自建 / 混合**。

## 六、跨库跳转规则（related 字段）

- 区域条目的 `related` 已指向职业KB 的具体 `§章节` 或文件名；职业KB 相关章节的「关联（区域层）」注记已反向指回区域条目。
- 智能体作答时若命中“区域宏观 + 学校落地”双重需要，应**同时检索两套库并标注各自来源与口径**，避免混用（区域流失率 11.7% 是企业侧调研值，不可等同于个人离职概率；L3 薪资是市场招聘分位数，非实发工资）。

## 七、使用须知（数据质量与红线）

1. **证据级别**：行动层为原文级（可回查 `kb_section` 行号）；区域层为索引级（只能引 `idx_region` 登记的数字），引用时须注明「据索引级条目」。
2. **样本量口径**：区域条目整体 N=116，各题有效回复 93–115 不等（分题回复率差异，非错误）；作答须注明“据大湾区企业调研样本”。
3. **日期语义**：区域条目 `effective_from: 2026-05-28` = 报告发布日；职业KB L3 薪资 `effective_from: 2025-10-01` = 统计期起始。两者语义不同，引用时分别说明。
4. **薪资铁律**：只写分位数+口径+期间；不给“起薪”承诺数字；样本量写「源页未公开」。
5. **未覆盖**：15 条缺口（G1–G15）见 `v_gap_code` 或本目录 JSON 的 `gaps` 字段，命中即答「现有资料未覆盖」，不得编造。
6. **来源等级**：`官方`须能指到文件/条款；`市场`须带来源页与统计期间；`自建`须注明“通用做法非官方规定”。把自建标成官方＝数据造假。
