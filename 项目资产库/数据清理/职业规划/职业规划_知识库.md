# 路书 · 职业规划知识库（A 组专业岗位 + D 组简历面试 · 合并版）

> 版本 v1.0｜编制 2026-11-03｜合并自《专业岗位知识库（A 组）》与《简历面试知识库（D 组）》
> 用途：面向广州市高职院校在校生（16–21 岁）的职业规划闭环——**兴趣 → 专业 → 岗位 → 技能/证书 → 薪资 → 简历 → 面试 → 权益**。本库覆盖其中「专业与岗位（A 组）」与「简历与面试（D 组）」两块。
>
> **铁律**：事实只来自知识库，没有就答「现有资料未覆盖」；金额/日期/条件须带文件名与生效日期；不做心理诊断、不承诺录取与薪资。涉及心理困扰、危机识别，转《大学生心理健康安全_知识库》。

### 跨库关联（路书知识库体系）

本知识库与另外两册互补，检索时按主题跳转：

- **本册《职业规划_知识库》**：专业→岗位→技能/证书→薪资→简历→面试→权益（**行动层**）。
- **《广州华南商贸职业学院_知识库》**：本校专业清单、培养方案、学费、官方就业数据（**事实层**）。本校专业怎么设、学费多少、官方就业率，查这一册。
- **《大学生心理健康安全_知识库》**：心理困扰识别、危机处理、求助系统（**支持层**）。本册不做心理诊断；涉及心理困扰、危机识别，一律转心理库。

交叉跳转点：本校专业/培养方案/学费 → 学校库 §三、§五；本校官方就业数据（落实率、平均薪酬）→ 学校库 §八；求职心理/就业焦虑 → 心理库 §6.5、§八。

## 〇、字段与来源等级口径（必读）

本库笔记（每篇 `###` 起头）必须同时带两个分类字段，二者不能混用：

| 字段 | 含义 | 本库取值 |
|---|---|---|
| `category`（主题分类） | 这条笔记讲什么主题 | `专业` / `岗位` / `证书` / `简历面试` |
| `source_level`（来源等级） | 这条信息的可信度来源 | `官方`（政策/标准/政府统计/法律）/ `市场`（招聘 JD、薪酬简报）/ `自建`（团队归纳） |

**为什么必须带 `source_level`**：审校员按此字段决定是否保留——`官方` 必须能指到文件与条款，`市场` 必须带来源页面与统计期间，`自建` 不要求外部出处但必须注明「这是通用做法，不是官方规定」。把 `自建` 内容标成 `官方` 会被判数据造假。

**两条不可逾越的红线**（写进任何内容前先对照）：

1. **薪资铁律**：只写「分位数 + 统计口径 + 期间」，禁止写「月薪 7000 起」这类承诺式表述。`source_level` 一律标 `市场`（薪酬简报系市场招聘大数据整理）。
2. **D 组三条线**：① 不代写简历全文（可给结构、动词替换表、弱点诊断）；② 不编面试真题（可说「这类岗位常问的三类问题」，不能编「某公司 2026 原题」）；③ 薪资谈判不给数字（可说「先让对方报价、结合本地分位数判断是否偏低」，不能替学生定期望数字）。

```yaml

title: 经历描写的动词与量化

published_at: 2026-11-03

```

**弱写法（避免）**：「负责社团活动，积累了经验。」
**强写法（推荐）**：「策划并执行 3 场社团活动，单场参与 80+ 人，负责宣传推送与现场统筹。」

核心公式：**做了什么（动词开头）+ 怎么做（方法/范围）+ 结果多少（数字）**。
常用强动词：搭建、优化、牵头、上线、提升、交付、排查、培训、策划、对接。

> 没有数字怎么办：用「覆盖 X 人」「缩短 X 天」「服务 X 次」这类可核实的量，别编百分比。

**① 自我介绍**：公式 = 我是谁 + 相关经历 1–2 条 + 为什么适合这个岗（30–60 秒）。
**② 「你的缺点是什么」**：框架 = 说一个**真实但非岗位核心致命**的缺点 + 你已在怎么改。避免说「我太追求完美」这类假缺点。
**③ 「为什么选我们/这个岗」**：框架 = 公司/行业了解 + 个人专业/兴趣匹配点，别空谈「平台大」。
**④ 「你最大的成就是什么」**：框架 = STAR（情境-任务-行动-结果），用数字收尾。
**⑤ 情景题「和同事/客户起冲突怎么办」**：框架 = 先倾听核对事实、再按流程沟通、必要时上报，体现合规与协作。

> 红线：只讲「这类岗位常问的三类问题」，**不编某公司具体原题**（除非有公开可引用来源）。

- **期限**：合同期 3 个月以上不满 1 年，试用期≤1 个月；1 年以上不满 3 年，≤2 个月；3 年以上固定期限/无固定期限，≤6 个月。**同一单位与同一劳动者只能约定一次试用期**。
- **工资**：试用期工资**不得低于**本单位同岗位最低档工资或劳动合同约定工资的 **80%**，并不得低于用人单位所在地最低工资标准。
- 以上信息来自《劳动合同法》第十九条、第二十条，请以官方最新发布文本为准。

- **套路**：以「高薪岗前培训」「包就业」为名，诱导学生签培训协议并**办理贷款**分期付学费，钱直接打给机构，学生没入职也要还债。
- **识别**：① 入职前要求先交钱/贷款培训，基本是坑；② 合同里出现「分期」「贷款」「服务费」要立刻停；③ 不轻信「零门槛高薪」。
- **建议**：正规岗前培训一般不向求职者收费；遇此情况先停、再核、后举报。
- 以上信息来自教育部等部门的培训贷风险提示，请以官方最新发布为准。

## 八、验证问句（上传后必做）

1. 软件技术专业的毕业生，能投哪三个岗位？每个岗位各需要什么技能？请说出你从哪个文件读到的。
2. 质检员在珠三角 2025 年第四季度的薪资 50 分位是多少？这个数字来自哪份文件、统计的是哪个期间？
3. 我们知识库里有没有「没有国家教学标准」的专业？是哪几个？你怎么判断的？（答：尚未逐专业核查，G-1 待补，不得编造名单）

**D 组（简历与面试）**
4. 简历里「负责社团活动」这句话问题在哪？应该改成什么？依据库里哪一条？（答：§四.2，弱写法改强写法：动词+内容+量化）
5. 面试被问「你的缺点是什么」，库里的回答框架是什么？（答：§五.2 ②，真实非致命缺点+已在改，避免假缺点）
6. 公司要求先交 8000 元培训费再上岗，这属于什么？建议走哪个渠道投诉？（答：§六.3 培训贷陷阱；投诉渠道 §六.5，12333 / 12345，带证据）

> 第 6 条特别注意：若智能体答出具体热线号码，而库里没有核实过的号码，说明它在编，须立刻回去查。本库仅收录已核实的 12333、12345。
